# Accessibility testing guide — 1.0.0

> 🌐 Language / Ngôn ngữ: **English** | [Tiếng Việt](ACCESSIBILITY-TEST-PLAN.vi.md)
The accessibility preflight separates automated browser checks from
PENDING HUMAN judgments when no accepted manual evidence is supplied.

Manual verification covers screen-reader walkthroughs, complete keyboard
workflows, layered contrast, real touch-device interaction and focus usability.
Only explicitly approved human evidence can mark those checks complete.
A passing automated check is not a WCAG conformance certification.

See [Accessibility verification](ACCESSIBILITY.md).
