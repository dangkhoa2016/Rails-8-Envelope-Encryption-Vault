# Accessibility — 1.0.0

> 🌐 Language / Ngôn ngữ: **English** | [Tiếng Việt](ACCESSIBILITY.vi.md)
The application includes automated keyboard, focus, reduced-motion and
responsive-layout checks. Manual screen-reader, contrast and touch-device
judgments require deployment-specific human verification.

Previously collected manual evidence was tied to an earlier internal
source candidate and is retained privately without relabeling it.
For the initial public source release, manual accessibility remains pending.
The project does not claim formal WCAG conformance.

Supply a newly approved manual evidence file using the
UX_ACCESSIBILITY_MANUAL_EVIDENCE_FILE environment variable.

See [Accessibility test plan](ACCESSIBILITY-TEST-PLAN.md).
