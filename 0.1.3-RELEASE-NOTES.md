# Ruby Envelope Vault 0.1.3

## Stable milestone

0.1.3 is the stable consolidation of the accepted 0.1.3-RC1 candidate and the 0.1.2-FIX46 upgrade baseline.

No new product behavior, database migration, or envelope-encryption data-model change is introduced relative to the accepted RC1 source.

## Acceptance carried into stable

The stable release re-runs and seals the complete release chain:

- repository and portability policy,
- Rails/system/security verification,
- automated UX/accessibility checks with manual accessibility explicitly pending,
- production HTTP security,
- failure handling and request correlation,
- logging redaction,
- CSRF/origin enforcement,
- rate limiting and abuse resistance,
- production session lifecycle,
- FIX46-to-0.1.3 upgrade compatibility,
- new-host recovery and isolated restore,
- public-package integrity,
- sealed-source integrity,
- explicit promotion and post-promotion evidence,
- off-host upload/download SHA-256 round-trip.

## Upgrade and rollback

The stable release keeps the FIX46 migration set unchanged. Production `db:migrate` is expected to be idempotent and no migration should remain pending.

Rollback was runtime-rehearsed before the stable fork:

`0.1.3-RC1 -> 0.1.2-FIX46 -> 0.1.3-RC1`

Both transitions returned health 200 and preserved sealed-source integrity.

## Evidence boundary

The release is evidence-driven but does not claim formal WCAG conformance. Kaggle remains a validated development/demo and release-proving environment, not the recommended host for irreplaceable production credentials.
