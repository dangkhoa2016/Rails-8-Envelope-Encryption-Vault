# Ruby Envelope Vault 0.1.6.1 — AWS KMS Production Boot Hotfix

Status: hotfix release candidate.

## Reason for hotfix

Exact DR recovery of promoted 0.1.6 proved that PostgreSQL restore and historical AWS KMS decrypt both worked, but production boot with `VAULT_KEY_PROVIDER=aws_kms` was blocked by a stale LocalFile-only guard in `config/initializers/production_environment_check.rb`.

The Registry already supported `aws_kms`; the production boot checker incorrectly rejected every non-`local_file` provider and always required a local `VAULT_KEK_DIR/<id>.key` file.

## Fix

- production boot checks are now provider-aware;
- `local_file` still requires `VAULT_KEK_DIR` and validates the local KEK file exactly as before;
- `aws_kms` requires an active KMS key id and `AWS_REGION` or `AWS_DEFAULT_REGION`;
- `aws_kms` no longer tries to locate a local KEK file;
- unknown providers continue to fail closed.

## Recovery proof
