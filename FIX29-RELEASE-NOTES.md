# FIX29 Release Notes — Release Evidence & Pre-promotion Sealing

FIX29 adds a non-secret release metadata JSON and a pre-promotion sealing command. The sealing command deliberately cannot promote the release; promotion remains an explicit separate operator action after reviewing evidence.

No cryptographic, schema, authentication, authorization, or vault payload semantics changed. Manual accessibility items remain PENDING unless actually tested by a human with the stated assistive technology/browser setup.
